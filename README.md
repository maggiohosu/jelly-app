# 말랑젤리 🍓

스포이드로 물감을 떨어뜨려 색을 바꾸고, 크리스탈 보석을 넣고, 손끝으로 출렁여 보는 3D 젤리를
iPhone 홈 화면 앱(PWA)으로 만든 프로젝트입니다.
[Three.js Awesome Graphics Agent Skills](https://github.com/scottstts/Threejs-Awesome-Graphics-Agent-Skills)의
`softbody-jelly`(XPBD 소프트바디 물리·굴절 그림자·WebGPU 코스틱)과 `raytraced-diamond`(보석 굴절) 기법을 바탕으로 만들었습니다.

## 설치 (iPhone)

1. Safari에서 `https://<GitHub 아이디>.github.io/jelly-app/` 열기
2. 하단 **공유** 버튼 → **홈 화면에 추가**
3. 홈 화면의 「말랑젤리」 아이콘으로 실행합니다. 주소창 없는 전체 화면으로 열리고, 한 번 실행한 뒤에는 오프라인에서도 동작합니다.

권장 환경은 **iOS 26 이상**(WebGPU)입니다. WebGPU가 없으면 자동으로 **라이트 모드**(WebGL2, 무지갯빛 코스틱만 제외)로 실행됩니다.

## 기능

| 기능 | 설명 |
|---|---|
| 스포이드 물감 | 빨강·노랑·파랑·분홍·보라·하늘 + 맑은 물. 끌어다 젤리 위에서 놓으면 한 방울, 그 자리에서 길게 누르면 똑똑 계속, 톡 누르면 꼭대기에 한 방울 |
| 색 섞임 | 떨어진 자리에서 마블처럼 번지고 출렁일수록 빨리 섞입니다. 색소는 빛 흡수계수(σ)로 더해지므로(비어-람베르트) 노랑+파랑=초록, 넣은 양에 정확히 비례합니다. 물은 연하게 만듭니다 |
| 크리스탈 보석 | 하트·다이아·별·물방울·달·벚꽃·사탕·리본·사과 9종 × 6색, 젤리 하나에 24개(레어 8개)까지. 보석함에서 끌어다 넣거나 '한 줌 쏟기'(공중에서 쏟아져 떨어지며 젤리에 콕 박힘). 젤리와 함께 휘고, 흔들면 이리저리 섞이며, 부딪히면 화음에 맞춘 '팅' 소리와 함께 은은히 빛납니다 |
| 크런치 소리 | 크런치 슬라임 ASMR을 합성합니다. 누르고 주무르면 알갱이가 '뽀득·톡톡' 터지고(움직임만큼 촘촘하게), 늘리면 끈적하게 '쩍', 손을 떼면 '뽁'. 젤리는 맑고 바삭하게, 슬랑이는 낮고 촉촉하게 |
| 슬랑이 | 툴바의 '젤리/슬랑이' 버튼으로 바로 전환. 슬랑이는 훨씬 말랑해 축 처지고, 당긴 모양이 그대로 남았다가 수십 초에 걸쳐 천천히 둥글게 돌아옵니다. 속에 파스텔 폼볼 알갱이 180개 |
| 빛 | 움직일수록 젤리 속이 자기 색으로 달아오르고 바닥에 색 조명이 번집니다. 크런치 소리마다 반짝이고, '높음' 화질에서는 후광(블룸)이 더해집니다 |
| 터치 | 젤리 잡아 늘리기(손가락마다 따로 잡혀 최대 3곳, 양쪽으로 쭉 당기기) · 빈 곳을 한 손가락으로 끌면 접시 기울이기(놓으면 수평 복귀) · 빈 곳 두 손가락 회전·확대 |
| 통통 | '통통' 버튼(누를 때마다 착지에 맞춰 계속 튐) · 젤리 두 번 톡톡 · 잡고 위로 휙 튕기며 놓기 |
| 토끼 주문 | 상단 주문서대로 만들고 🥕를 누르면 털 인형 토끼가 와서 젤리를 통째로 받쳐 들고 와삭와삭 먹습니다. 주문은 색 이름 47가지(최근 5개는 반복 안 함)에 친밀도가 오를수록 보석 2종·글리터/별사탕 토핑·슬랑이·모양 조건이 붙고 색 판정도 엄격해집니다. 주문서에 조건 아이콘(모양·보석×개수·토핑·슬랑이)이 함께 보이고, **✨ 이 주문으로 새 젤리** 버튼 한 번이면 주문에 맞는 모양·바탕색 젤리가 바로 나옵니다(다 먹은 뒤에는 자동). 색(70 %) + 조건(30 %)으로 ★1~3(색 허용 범위는 v9.2에서 전 레벨 2배로 넓어졌고, 아무것도 넣지 않은 젤리는 최대 ★2), 레어 보석을 넣으면 ★+1(★4 '특별') → 금화 15/23/30/40 (+레어 보석 1개당 5) |
| 주문 종류 | ✨ 황금 주문(Lv3+, 금화 ×3, ★3이면 무료 카드 1장) · 🧐 까다로운 날(Lv5+, 토끼가 외알 안경, 금화 ×2) · 🙈 기억 주문(Lv4+, 5초 뒤 글이 숨고 톡 누르면 금화 5개로 5초 다시 보기). ⚡ 타임 보너스: 주문을 받고 30초 안에 주면 +50 %, 1분 안이면 +25 % (화면이 보일 때만 잼) |
| 콤보 | ★3 이상을 연달아 받으면 🔥콤보: 2연속 ×1.2, 3~4연속 ×1.5, 5연속부터 ×2. 보상 카드에 기본·레어·콤보·주문 종류·시간 보너스 내역이 나옵니다 |
| 토끼의 반응 | ★1이면 1/3 확률로 한 입 먹고 '퉤'(금화 1~50 감소), 1/5 확률로 킁킁 냄새만 맡고 절레절레하다 뒷발로 뻥! 차 버립니다(젤리가 접시 끝까지 굴러감, 금화 1~50 감소). 둘 다 젤리는 남아 있어 고쳐서 다시 줄 수 있고 콤보는 끊겨요 |
| 고양이·새 | 고양이 젤리는 5초마다 하품 또는 냥냥펀치, 새 젤리는 7초마다 날갯짓하다 퐁 주저앉거나 짹짹짹 — 소리와 표정까지(토끼가 올 때는 쉬어요) |
| 모양 | 꽃(Lv1) · 푸딩(Lv2) · 케이크 조각(Lv4) · 곰젤리(Lv6) · 고양이(Lv8) · 새(Lv10). 툴바 모양 버튼에서 고르면 새 젤리가 떨어집니다. 모양마다 대표 꾸밈(무지개 층과 체리, 보라색 곰 얼굴, 딸기 젤리 고양이 (딸기 조각·수염), 무지갯빛 새, 분홍 그라데이션 푸딩)이 기본으로 들어 있고 물감·보석은 그 위에 자유롭게. 떨어뜨린 물감만 퍼지고 대표 무늬(케이크 층, 새의 머리·날개 색)는 그대로 남아요 |
| 카드 뽑기 | 🎴 금화 100개(또는 무료 카드)로 뒷면 카드 3장 중 하나 선택 → 흔들림 → 뒤집기 → 등급별 축하. 레어 보석 25종이 **10개 묶음**으로 들어오고, 같은 보석이 또 나오면 +10개와 함께 글리터 → 금빛 → 무지개빛 업그레이드(무지개빛이면 +10개만). 100장에 1장은 아직 잠긴 모양을 바로 여는 **모양 카드**(나중에 그 레벨이 되면 "이미 있어요" + 금화 25), 그다음 30장에 1장은 아직 없는 🧙 마녀 모자·🪄 마법지팡이를 주는 **꾸미기 카드**(둘 다 있으면 보석) |
| 레어 보석 재고 | 레어 보석은 넣을 때마다 1개씩 줄고, 보석함에는 남은 개수 순으로(0개는 회색으로 맨 뒤) 표시됩니다. 먹이지 않고 새 젤리·모양 변경·'이 주문으로 새 젤리'로 바꾸면 젤리 속 레어 보석은 돌아오고, 토끼가 먹은 것은 사라져요 |
| 친밀도 | 먹일 때마다 ♥ 경험치. 레벨이 오를 때마다 🎁 선물상자(금화·레어 보석 10개·무료 카드 중 하나). Lv2 주황+푸딩 · Lv3 글리터+리본 · Lv4 연두+케이크+꽃무늬 접시 · Lv5 별사탕+안경 · Lv6 금펄+곰젤리 · Lv7 목도리+별밤 · Lv8 야광+고양이 · Lv9 왕관 · Lv10 새+딸기 테이블 · Lv12 요정 날개 |
| 토끼 배부름 🍮 | 토끼가 젤리를 먹을 때마다(퉤·뻥은 빼고) 툴바 위 배부름 게이지가 1칸씩, 20개면 꽉 차요. 배가 커질수록 토끼 배가 동글동글해지고, 꽉 차면 배를 잡고 '끄억' 트림하며 와요. 꽉 찬 동안은 **모든 평가가 ★−1**(최소 ★1, 깎인 ★1도 퉤·뻥 확률 그대로) — 게이지가 빨갛게 깜빡이고 "너무 배불러요!" |
| 화장실 🚽 | 배가 꽉 차면 🥕 옆 🚽 버튼이 깜빡여요. 누르면 날개 달린 하얀 변기가 뿅 나타나고 토끼가 올라가 끙… → 물 내림 → 방긋 웃고 내려와요(약 7초, 그동안 시간 보너스·기억 주문 타이머·고양이/새 동작은 멈춤). 게이지는 0으로, 업적 '첫 화장실'(+15)·'화장실 10회'(+30) |
| 기분 최고 😊 | 화장실 다녀온 뒤 **다음 5번**은 꾸민 젤리(물감·보석·토핑을 하나라도 넣은 젤리)에 ★+1. 주문서에 "기분 최고 ★+1 · 남은 n회", 보상 카드에 배지. ★4에서 넘치면 ★4 그대로 + 금화 10('넘친 별'). 아무것도 안 넣은 젤리는 보너스도 횟수 차감도 없어요 |
| 꾸미기·테마 | ⚙ 설정의 '토끼 꾸미기'(머리·얼굴·목·등·지팡이 한 개씩, 꽃 머리띠·별 망토는 업적 보상, 🧙 마녀 모자·🪄 마법지팡이는 카드 뽑기 30장에 1장 꼴로 나오는 **꾸미기 카드**에서만 — 지팡이는 등에 비스듬히 메고 와서 반짝 휘둘러요)와 '접시·배경 테마' 5종(무지개 구름은 색 도감 20개 또는 모양 6종) |
| 도감 | 📖 레어 보석(남은 개수) · 작품 앨범(최근 60개) · 색 도감(47색, 10/20/30/전부 모으면 보상) · 업적 32개(금화·칭호, 칭호는 친밀도 옆에 표시) · 숨은 레시피 8개(힌트만 보여요, 찾으면 토끼가 깜짝 기뻐하고 금화 25) |
| 설정 | 새 젤리·소리 켜기/끄기, 젤리 바탕색, 말랑함·출렁임·미끄러움, 빛 세기, 크런치·보석·출렁 소리·토끼/금화 볼륨, 화질 |

## 구조

```
메인 스레드              sim-worker                       optics-worker
(렌더링·입력·소리·UI)     (240Hz XPBD 젤리 + 물감 + 보석)   (굴절 그림자·시선 두께)
   │ tick(dt, 이벤트) ───▶ │                                  │
   │ ◀── 표면·법선·색(σ)·보석 자세 (버퍼 전송)                 │
   │ 표면 스냅샷 + 카메라 ───────────────────────────────────▶ │ (8~20Hz)
   │ ◀──────────────────────────────── 그림자 텍스처·두께 ──── │
   └─ WebGPU: GPU 코스틱 compute (화질에 따라 15~60Hz) → (후광) → 화면
```

- `src/core/` — 물리·광학·월드. three.js 의존이 없어 Worker에서 실행됩니다.
  - `softbody.js`, `cage.js`, `optics.js`: 원본과 **비트 단위로 같은 결과**를 내는 포팅입니다(`tests/golden.test.mjs`, `tests/optics.test.mjs`). 할당을 없애서 물리 1.7배, 표면 3.6배, 광학 1.6배 빨라졌습니다.
  - `world.js`: 물감 방울(색소 보존 확산), 슬랑이(소성 변형·알갱이), 보석(변형 전 좌표에 박혀 젤리를 따라 움직임, 충돌·덜컥임 이벤트), 접시 기울기를 다룹니다.
- `src/render/` — 장면(기울어지는 접시, 카메라 조작, 후광), 젤리 뷰(정점별 σ 재질·발광·물방울 연출), 보석(TSL 레이트레이싱 크리스탈), 터치 입력, GPU 코스틱(원본 모듈 + 갱신 빈도 제한·접시 좌표 패치).
- `src/app/` — 앱 흐름, 합성 크런치·보석음·효과음(`audio.js`), 슬랑이 알갱이(`render/beads.js`), 화질 자동 조절, UI.
- `vendor/three/` — three.js r185.1(오프라인 동작). 로컬 패치 내역은 `vendor/three/PATCHES.md`를 보세요.

### 화질 자동 조절

프레임 간격을 디스플레이 주사율(120/60/30Hz, 30Hz는 저전력 모드)과 비교해서 버거우면 한 단계씩 내립니다.
양보하는 순서는 **코스틱(빈도 → 끄기) → 후광 → 해상도**입니다. 젤리 물리(240Hz)와 보석 반짝임은 끝까지 유지합니다.
GPU 오류가 나면 코스틱만 끄고, GPU 장치가 끊기면 한 번 재시작하고, 1분 안에 또 끊기면 라이트 모드로 전환합니다.

## 배포 (GitHub Pages)

1. 저장소 **Settings → Pages → Build and deployment**
2. Source: **Deploy from a branch**, Branch: **main** / **(root)** → **Save**
3. 1~2분 뒤 `https://<GitHub 아이디>.github.io/jelly-app/` 에 접속합니다.

빌드 과정은 없습니다. 업데이트할 때는 `sw.js`의 `VERSION`을 올려야 이미 설치한 폰도 새 파일을 받습니다(다음 실행부터 적용).

## 개발

```sh
npm install          # 테스트용 three (원본 비교에 사용)
npm test             # 원본 동일성 · 광학 · 안정성 · 물감/보석 월드 · 화질 조절
npm run test:audio   # 크런치·보석음 오프라인 렌더 검사 (Playwright/Chromium 필요)
npm run serve        # http://localhost:8123  (?lite=1 → WebGL2 강제)
```

`tests/gems-preview.html`: 보석 9종 미리보기(`?color=`, `?quality=`, `?lite=1`).
`tests/rare-gems-preview.html`: 레어 보석 25종(`?tier=0|1|2`, `?compare=`), `tests/rabbit-preview.html`: 토끼(`?mood=`, `?t=`, `?quality=`).

## 실기기 체크리스트

자동 테스트는 Linux 헤드리스 Chromium에서 돌렸습니다. 이 환경의 WebGPU는 몇 초 만에 장치가 끊기는 버그가 있어서, 화면 검증은 라이트 모드로 했습니다.
아래 항목은 iPhone에서 직접 확인해야 합니다.

- [ ] iOS 26 Safari에서 배지 없이(WebGPU) 실행되고, 바닥에 무지갯빛 코스틱이 보이는지(⚙ 상태 줄: `WebGPU · 코스틱·후광`)
- [ ] 스포이드를 끌어 놓을 때 손가락에 가리지 않고 물방울이 떨어지는지, 길게 누르면 연속으로 떨어지는지
- [ ] 노랑 몇 방울 + 파랑 몇 방울 → 초록으로 섞이는지, 물방울로 연해지는지
- [ ] 보석이 레퍼런스처럼 핑크 크리스탈로 반짝이는지, 흔들면 '팅' 소리가 나는지
- [ ] 홈 화면 앱을 백그라운드에 갔다 와도 화면을 한 번 터치하면 소리가 다시 나는지
- [ ] 두 손가락으로 젤리 양쪽을 잡아 당길 수 있는지 · '통통' 연타 시 리듬 있게 튀는지
- [ ] 젤리를 주무르면 크런치 소리가 나고 멈추면 잦아드는지(무음 스위치 해제 상태), 듣던 음악이 끊기지 않는지
- [ ] 슬랑이로 바꿔 쭉 늘리면 모양이 남았다가 천천히 둥글게 돌아오는지, 1분 뒤 발열·프레임
- [ ] 빈 곳을 끌면 접시가 기울어 젤리가 미끄러지고, 놓으면 수평으로 돌아오는지 · 두 손가락 회전·확대
- [ ] 1~2분 사용 후 발열·프레임 확인. 버벅이면 화질이 자동으로 내려갔는지(⚙ 상태 줄)
- [ ] 비행기 모드로 홈 화면 앱을 다시 실행해도 열리는지(오프라인)
- [ ] 🥕: 토끼 털이 보송하게 보이는지, 젤리를 두 손으로 들고 먹는 동안 버벅이지 않는지(털은 '높음' 화질에서만 최고 단계)
- [ ] 카드 뽑기 연출·금화 비가 끊김 없이 나오는지, 효과음(와삭·뀨·짤랑·팡파르)
- [ ] 레어 보석이 젤리 속에서 원본 이미지처럼 보이는지(글리터 반짝임·금빛·무지개빛)
- [ ] 모양 버튼으로 푸딩·케이크·곰·고양이·새를 바꿔 볼 때 처음 한 번만 잠깐 멈칫하고(모양 생성) 이후엔 바로 바뀌는지, 눈·코·체리가 젤리를 따라 움직이는지
- [ ] 토끼가 젤리를 들고 먹을 때 쭉 늘어나지 않고 통째로 들리는지, 퉤 뒤 젤리가 그대로 남는지
- [ ] ★1 '뻥': 토끼가 킁킁·절레절레 후 뒷발로 차면 젤리가 데굴 굴러 접시 끝에 멈추는지, 효과음(킁킁·뻥)
- [ ] 주문서 '✨ 이 주문으로 새 젤리': 모양 주문이면 그 모양, 아니면 바탕색 젤리가 바로 나오는지 · 다 먹은 뒤 다음 주문용 젤리가 자동으로 나오는지
- [ ] 황금 주문 카드가 반짝이며 효과음이 나는지 · 기억 주문이 5초 뒤 숨고 톡 누르면 금화 5개로 다시 보이는지 · 까다로운 날 토끼가 외알 안경을 쓰는지
- [ ] ⚡ 시간 보너스 막대가 줄어들고(앱을 내렸다 올리면 그동안은 멈춤) 30초·60초에 +50 % → +25 % → 사라지는지
- [ ] 레어 보석 개수가 넣을 때마다 줄고 순서가 바뀌는지, 0개는 회색 + "보석이 없어요", 새 젤리로 바꾸면 돌아오는지
- [ ] 보상 카드 내역(기본·레어·🔥콤보·황금·⚡시간) 뒤에 새 색 발견·숨은 레시피·업적·선물상자가 겹치지 않고 차례로 나오는지
- [ ] 고양이(5초마다 하품/냥냥펀치)·새(7초마다 날갯짓/짹짹) 동작과 소리가 맞는지, 가만히 둬서 잠든 젤리도 움직이는지
- [ ] 토끼 꾸미기(리본·안경·목도리·왕관·날개·꽃 머리띠·망토)가 다음 방문 때 보이는지 · 테마 5종에서 글자가 잘 읽히는지(특히 별밤)
- [ ] 업데이트 후 첫 실행: 기존 레어 보석이 각 10개로 바뀌고 금화·레벨이 그대로인지
- [ ] v9 업데이트 후 첫 실행: 배부름 게이지가 0/20, 금화·레벨·꾸미기가 그대로인지
- [ ] 🍮 게이지가 툴바 위 오른쪽에 잘 보이고(보석함·모양 서랍을 열면 숨음) 먹일 때마다 1칸씩 차는지, 토끼 배가 점점 동그래지는지
- [ ] 20개째에 "🚽 화장실에 보내 주세요! (그동안 별 −1)" 안내 → 게이지가 빨갛게 깜빡이고 🚽 버튼이 통통 튀는지
