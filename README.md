# 말랑젤리 🍓

스포이드로 물감을 떨어뜨려 색을 바꾸고, 크리스탈 보석을 넣고, 손끝으로 출렁여 보는 3D 젤리를
iPhone 홈 화면 앱(PWA)으로 만든 프로젝트입니다.
[Three.js Awesome Graphics Agent Skills](https://github.com/scottstts/Threejs-Awesome-Graphics-Agent-Skills)의
`softbody-jelly`(XPBD 소프트바디 물리·굴절 그림자·WebGPU 코스틱)과 `raytraced-diamond`(보석 굴절) 기법을 바탕으로 만들었습니다.

## 설치 (iPhone)

1. Safari에서 `https://<GitHub 아이디>.github.io/jelly-app/` 열기
2. 하단 **공유** 버튼 → **홈 화면에 추가**
3. 홈 화면의 「말랑젤리」 아이콘으로 실행합니다. 주소창 없는 전체 화면으로 열리고, 한 번 실행한 뒤에는 오프라인에서도 동작합니다.

권장 환경은 **iOS 26 이상**(WebGPU)입니다. WebGPU가 없으면 자동으로 **라이트 모드**(WebGL2, 무지갯빛 코스틱만 제외)로 실행됩니다.

## 기능

| 기능 | 설명 |
|---|---|
| 스포이드 물감 | 빨강·노랑·파랑·분홍·보라·하늘 + 맑은 물. 끌어다 젤리 위에서 놓으면 한 방울, 그 자리에서 길게 누르면 똑똑 계속, 톡 누르면 꼭대기에 한 방울 |
| 색 섞임 | 떨어진 자리에서 마블처럼 번지고 출렁일수록 빨리 섞입니다. 색소는 빛 흡수계수(σ)로 더해지므로(비어-람베르트) 노랑+파랑=초록, 넣은 양에 정확히 비례합니다. 물은 연하게 만듭니다 |
| 크리스탈 보석 | 하트·다이아·별·물방울·달·벚꽃·사탕·리본·사과 9종 × 6색. 보석함에서 끌어다 넣거나 '한 줌 쏟기'(공중에서 쏟아져 떨어지며 젤리에 콕 박힘). 젤리와 함께 휘고, 흔들면 이리저리 섞이며, 부딪히면 화음에 맞춘 '팅' 소리와 함께 은은히 빛납니다 |
| 피아노 선율 | 젤리가 움직이는 만큼 합성 피아노가 즉흥 선율(C 장조 5음음계, C–G–Am–F)을 연주합니다. 높이 끌어올리면 높은 음 |
| 빛 | 움직일수록 젤리 속이 자기 색으로 달아오르고 바닥에 색 조명이 번집니다. 선율의 음마다 반짝이고, '높음' 화질에서는 후광(블룸)이 더해집니다 |
| 터치 | 젤리 잡아 늘리기(손가락마다 따로 잡혀 최대 3곳, 양쪽으로 쭉 당기기) · 빈 곳을 한 손가락으로 끌면 접시 기울이기(놓으면 수평 복귀) · 빈 곳 두 손가락 회전·확대 |
| 통통 | '통통' 버튼(누를 때마다 착지에 맞춰 계속 튐) · 젤리 두 번 톡톡 · 잡고 위로 휙 튕기며 놓기 |
| 설정 | 젤리 바탕색(베리·민트·허니·투명), 말랑함·출렁임·미끄러움, 빛 세기, 피아노·보석·효과음 볼륨, 선율 빠르기, 화질 |

## 구조

```
메인 스레드              sim-worker                       optics-worker
(렌더링·입력·소리·UI)     (240Hz XPBD 젤리 + 물감 + 보석)   (굴절 그림자·시선 두께)
   │ tick(dt, 이벤트) ───▶ │                                  │
   │ ◀── 표면·법선·색(σ)·보석 자세 (버퍼 전송)                 │
   │ 표면 스냅샷 + 카메라 ───────────────────────────────────▶ │ (8~20Hz)
   │ ◀──────────────────────────────── 그림자 텍스처·두께 ──── │
   └─ WebGPU: GPU 코스틱 compute (화질에 따라 15~60Hz) → (후광) → 화면
```

- `src/core/` — 물리·광학·월드. three.js 의존이 없어 Worker에서 실행됩니다.
  - `softbody.js`, `cage.js`, `optics.js`: 원본과 **비트 단위로 같은 결과**를 내는 포팅입니다(`tests/golden.test.mjs`, `tests/optics.test.mjs`). 할당을 없애서 물리 1.7배, 표면 3.6배, 광학 1.6배 빨라졌습니다.
  - `world.js`: 물감 방울(색소 보존 확산), 보석(변형 전 좌표에 박혀 젤리를 따라 움직임, 충돌·덜컥임 이벤트), 접시 기울기를 다룹니다.
- `src/render/` — 장면(기울어지는 접시, 카메라 조작, 후광), 젤리 뷰(정점별 σ 재질·발광·물방울 연출), 보석(TSL 레이트레이싱 크리스탈), 터치 입력, GPU 코스틱(원본 모듈 + 갱신 빈도 제한·접시 좌표 패치).
- `src/app/` — 앱 흐름, 합성 피아노·보석음·효과음(`audio.js`), 화질 자동 조절, UI.
- `vendor/three/` — three.js r185.1(오프라인 동작). 로컬 패치 내역은 `vendor/three/PATCHES.md`를 보세요.

### 화질 자동 조절

프레임 간격을 디스플레이 주사율(120/60/30Hz, 30Hz는 저전력 모드)과 비교해서 버거우면 한 단계씩 내립니다.
양보하는 순서는 **코스틱(빈도 → 끄기) → 후광 → 해상도**입니다. 젤리 물리(240Hz)와 보석 반짝임은 끝까지 유지합니다.
GPU 오류가 나면 코스틱만 끄고, GPU 장치가 끊기면 한 번 재시작하고, 1분 안에 또 끊기면 라이트 모드로 전환합니다.

## 배포 (GitHub Pages)

1. 저장소 **Settings → Pages → Build and deployment**
2. Source: **Deploy from a branch**, Branch: **main** / **(root)** → **Save**
3. 1~2분 뒤 `https://<GitHub 아이디>.github.io/jelly-app/` 에 접속합니다.

빌드 과정은 없습니다. 업데이트할 때는 `sw.js`의 `VERSION`을 올려야 이미 설치한 폰도 새 파일을 받습니다(다음 실행부터 적용).

## 개발

```sh
npm install          # 테스트용 three (원본 비교에 사용)
npm test             # 원본 동일성 · 광학 · 안정성 · 물감/보석 월드 · 화질 조절
npm run test:audio   # 합성 피아노·보석음 오프라인 렌더 검사 (Playwright/Chromium 필요)
npm run serve        # http://localhost:8123  (?lite=1 → WebGL2 강제)
```

`tests/gems-preview.html`: 보석 9종 미리보기(`?color=`, `?quality=`, `?lite=1`).

## 실기기 체크리스트

자동 테스트는 Linux 헤드리스 Chromium에서 돌렸습니다. 이 환경의 WebGPU는 몇 초 만에 장치가 끊기는 버그가 있어서, 화면 검증은 라이트 모드로 했습니다.
아래 항목은 iPhone에서 직접 확인해야 합니다.

- [ ] iOS 26 Safari에서 배지 없이(WebGPU) 실행되고, 바닥에 무지갯빛 코스틱이 보이는지(⚙ 상태 줄: `WebGPU · 코스틱·후광`)
- [ ] 스포이드를 끌어 놓을 때 손가락에 가리지 않고 물방울이 떨어지는지, 길게 누르면 연속으로 떨어지는지
- [ ] 노랑 몇 방울 + 파랑 몇 방울 → 초록으로 섞이는지, 물방울로 연해지는지
- [ ] 보석이 레퍼런스처럼 핑크 크리스탈로 반짝이는지, 흔들면 '팅' 소리가 나는지
- [ ] 홈 화면 앱을 백그라운드에 갔다 와도 화면을 한 번 터치하면 소리가 다시 나는지
- [ ] 두 손가락으로 젤리 양쪽을 잡아 당길 수 있는지 · '통통' 연타 시 리듬 있게 튀는지
- [ ] 젤리를 흔들면 피아노 선율이 나오고 멈추면 잦아드는지(무음 스위치 해제 상태), 듣던 음악이 끊기지 않는지
- [ ] 빈 곳을 끌면 접시가 기울어 젤리가 미끄러지고, 놓으면 수평으로 돌아오는지 · 두 손가락 회전·확대
- [ ] 1~2분 사용 후 발열·프레임 확인. 버벅이면 화질이 자동으로 내려갔는지(⚙ 상태 줄)
- [ ] 비행기 모드로 홈 화면 앱을 다시 실행해도 열리는지(오프라인)
