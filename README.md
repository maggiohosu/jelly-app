# 말랑젤리 🍓

손끝으로 잡아 늘리고, 흔들고, 기울여 보는 3D 젤리를 iPhone 홈 화면 앱(PWA)으로 만든 프로젝트입니다.
[Three.js Awesome Graphics Agent Skills](https://github.com/scottstts/Threejs-Awesome-Graphics-Agent-Skills)의
`softbody-jelly` 스킬(XPBD 소프트바디 물리, 굴절 그림자, WebGPU 코스틱)을 기반으로 모바일에 맞게 다시 구성했습니다.

## 설치 (iPhone)

1. Safari에서 `https://<GitHub 아이디>.github.io/jelly-app/` 열기
2. 하단 **공유** 버튼 → **홈 화면에 추가**
3. 홈 화면의 「말랑젤리」 아이콘으로 실행. 주소창 없는 전체 화면으로 열리고, 한 번 실행한 뒤에는 오프라인에서도 동작합니다.

권장 환경: **iOS 26 이상** (WebGPU). 그 이하 버전이나 WebGPU가 없는 기기에서는 자동으로 **라이트 모드**(WebGL2, 무지갯빛 코스틱만 제외)로 실행됩니다.

## 기능

| 기능 | 설명 |
|---|---|
| 잡아 늘리기 | 젤리를 누른 채 끌면 늘어나고, 놓으면 출렁 |
| 카메라 | 빈 곳을 한 손가락으로 밀면 회전, 두 손가락으로 확대/축소 |
| 기울기 | 폰을 탁자에 눕힌 상태가 수평입니다. 기울이면 미끄러지고(최대 45°까지 반영), 3° 이하는 무시해서 배터리를 아낍니다 |
| 흔들기 | 폰을 흔들면 젤리가 튀어 오름 |
| 맛 | 베리 · 민트 · 허니 (색과 빛 흡수 계수가 함께 바뀜) |
| 효과음 | Web Audio로 실시간 합성. 듣던 음악을 끊지 않고(ambient), 무음 스위치를 켜면 소리가 나지 않음 |
| 화질 자동 조절 | 프레임 간격을 재서 높음 → 중간 → 낮음 단계로 자동 조절 (ⓘ 메뉴에서 직접 고를 수도 있음) |

## 구조

```
메인 스레드            sim-worker                 optics-worker
(렌더링·입력·UI)        (240Hz XPBD 물리)          (굴절 그림자·두께)
     │  tick(dt, 손가락, 이벤트) ─▶ │                         │
     │ ◀─ 표면 위치·법선 (전송)     │                         │
     │  표면 스냅샷 + 카메라 ─────────────────────────────▶ │  (10~24Hz)
     │ ◀──────────────────────── 그림자 텍스처·두께 ──────── │
     └─ WebGPU: GPU 코스틱 compute (15~60Hz) → 렌더
```

- `src/core/` — 물리·광학 코어. three.js 의존이 없어 Worker에서 실행됩니다.
  원본과 **비트 단위로 같은 결과**를 내도록 포팅했고(`tests/golden.test.mjs`, `tests/optics.test.mjs`),
  할당을 없애서 물리 1.7배, 표면 갱신 3.6배, 광학 1.6배 빨라졌습니다.
- `src/workers/` — 물리/광학 Worker. 버퍼를 주고받는 transfer 방식이라 매 프레임 복사 비용이 거의 없습니다
  (GitHub Pages는 COOP/COEP 헤더를 줄 수 없어 SharedArrayBuffer를 쓸 수 없음).
- `src/render/` — 장면, 젤리 재질, 터치 입력, GPU 코스틱(원본 모듈 + 갱신 빈도 제한 패치).
- `src/app/` — 앱 흐름, 센서, 사운드, 화질 조절.
- `vendor/three/` — three.js r185.1 (CDN 없이 오프라인 동작). 로컬 패치 내역은 `vendor/three/PATCHES.md`.

### 원본 대비 추가·변경점

- 물리는 모든 기기에서 원본과 같은 **240Hz**를 유지합니다. 120Hz로 낮추면 정지 상태에서도 부피가 88%로 주저앉아 모양이 달라지기 때문입니다.
  Worker가 따라가지 못할 때만 비상용 160Hz로 내립니다(정지 부피 93.5%).
- 젤리가 화면 밖으로 나가지 않도록 접시 벽(반지름 7.2cm)을 추가했고, 손가락 목표점도 접시 안으로 제한합니다.
- 기울기를 주면 바닥 마찰이 '젖은 접시' 값으로 바뀝니다. 원본 마찰(0.65)이면 33° 넘게 기울여야 미끄러지기 때문입니다.
- GPU 오류가 나면 코스틱만 끄고 계속 실행합니다. GPU 장치가 끊기면 한 번 재시작하고, 1분 안에 또 끊기면 라이트 모드로 전환합니다.

## 배포 (GitHub Pages)

1. 저장소 **Settings → Pages → Build and deployment**
2. Source: **Deploy from a branch**, Branch: **main** / **(root)** → **Save**
3. 1~2분 뒤 `https://<GitHub 아이디>.github.io/jelly-app/`에서 접속할 수 있습니다

빌드 과정은 없습니다. 저장소의 파일이 그대로 서비스됩니다.

### 업데이트할 때 (중요)

`sw.js`의 `VERSION`을 올려야(`"v1"` → `"v2"`) 이미 설치된 폰도 새 파일을 받습니다.
새 버전은 백그라운드에서 받아 두었다가 **다음 실행부터** 적용됩니다.

## 개발

```sh
npm install          # 테스트용 three (원본 비교에 사용)
npm test             # 원본 동일성 · 광학 · 안정성 · 화질 조절 테스트
npm run serve        # http://localhost:8123  (?lite=1 → WebGL2 강제)
```

## 실기기 체크리스트

이 저장소의 테스트는 Linux 헤드리스 Chromium에서 돌렸습니다. 아래 항목은 iPhone에서 직접 확인해야 합니다.

- [ ] iOS 26 Safari에서 배지 없이(WebGPU) 실행되고, 바닥에 **무지갯빛 굴절광(코스틱)**이 보이는지
- [ ] ⓘ 메뉴의 상태 줄이 `WebGPU · 코스틱 켜짐`인지
- [ ] 젤리를 잡고 늘릴 때 화면이 회전하지 않는지, 빈 곳 드래그는 회전·핀치는 확대되는지
- [ ] 시작 시 '모션 및 방향' 권한 팝업 → 허용 → 폰을 눕혀서 기울이면 기운 방향으로 미끄러지는지
- [ ] 가로로 돌렸을 때도 기울기 방향이 맞는지
- [ ] 흔들면 튀어 오르는지, 효과음이 나는지(무음 스위치 해제 상태), 듣던 음악이 끊기지 않는지
- [ ] 홈 화면 앱에서 비행기 모드로 다시 실행해도 열리는지(오프라인)
- [ ] 1~2분 사용 후 발열·프레임. 버벅이면 ⓘ 메뉴에서 화질이 자동으로 내려갔는지
- [ ] 앱을 내렸다가 돌아왔을 때 정상 복귀하는지
